┌─────────────────────────────────────────────────────────────────────────────┐
│ PHOTO CAPTURE WORKFLOW                                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1. [Jetson] Timer fires (every 5 seconds)                                 │
│      │                                                                      │
│      ▼                                                                      │
│  2. [Jetson] Send UDP packet: 55 66 01 01 00 00 00 0c 00 34 ce             │
│      │                                                                      │
│      ▼                                                                      │
│  3. [Camera] Capture 4K photo → Save to SD card                            │
│      │                                                                      │
│      ▼                                                                      │
│  4. [Jetson] Poll media server: getmediacount                              │
│      │                                                                      │
│      ▼                                                                      │
│  5. [Jetson] Request photo URL: getmedialist                               │
│      │                                                                      │
│      ▼                                                                      │
│  6. [Jetson] HTTP GET: Download JPEG                                       │
│      │                                                                      │
│      ▼                                                                      │
│  7. [Jetson] Decode → Save locally → Publish to ROS2                       │
│                                                                             │
│  Total cycle time: ~3-5 seconds                                            │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
