#   opencv-python and sahi are pinned to numpy-1-ABI-compatible versions for the
#   same reason (sahi 0.12+ forces opencv >= 4.12, which is a numpy-2 build).
#
# For an exact-version restore, see requirements_jetson.lock.txt instead.
